# PolicyVault

Your Policies. Your Payments. Your Peace of Mind.

PolicyVault is a personal insurance policy management system designed to help users store, manage, track, and monitor their insurance policies and premium payments.

## Technology Stack

### Frontend
- React.js
- JavaScript
- Bootstrap 5
- Axios
- React Router
- Recharts

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication
- JWT
- bcrypt
